# SaaS Business Analysis Portfolio — CloudSync Pro

## Project Overview
End-to-end business analysis of a SaaS subscription product,
identifying key churn drivers and recommending data-backed solutions.

## Problem Statement
Free-tier customer churn rate at 45%, costing significant upgrade 
revenue. Analysis identified early feature adoption as the key predictor.

## Key Findings
- Free users churn 9x faster than Enterprise customers
- 78% of churn occurs within 14 days of signup
- Customers using 4+ features in Week 1 have 3x lower churn

## Recommendation
Automated 4-touch email onboarding sequence targeting feature discovery.
Projected to reduce churn from 45% to 25% in 90 days.
